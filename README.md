# Tawf Labs

Landing page for [Tawf Labs](https://github.com/tawf-labs/tawf-labs), the company building:

- **Tawf Foundation** ([tawf.foundation](https://tawf.foundation)): infrastructure for Islamic foundations.
- **Tawf Finance** ([tawf.finance](https://tawf.finance)): infrastructure for Islamic finance institutions.

The design follows the Tawf Foundation site, rendered strictly in black and white.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # type-check
npm run build    # production build in dist/
```

Stack: Vite, React 19, TypeScript, Tailwind CSS v4, Motion, Lucide.
